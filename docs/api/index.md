# API reference

This section documents the **stable user API** exported by `symbopt.api`. The pages are hand-organized by mathematical role, while signatures and docstrings are pulled from the installed package with Sphinx autodoc.

Most users should begin with `minimize()` and use the lower-level functions only when they need direct control over a solver family.
