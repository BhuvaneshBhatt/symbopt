# Stable public symbol registry

This registry is the explicit documentation contract for every name exported by `symbopt.api`. Each entry names the canonical API page responsible for that public symbol. Documentation tests require this registry to match `symbopt.api.__all__` exactly and require the owner page to mention the corresponding fully qualified symbol.
